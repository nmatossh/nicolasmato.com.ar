# Nicolás Mato - Portfolio Profesional

Sitio web personal y portafolio de **Nicolás Mato**, Consultor de Infraestructura IT e Ingeniero SR Unix/Linux. 

Este proyecto presenta una landing page moderna, minimalista y profesional que destaca perfiles técnicos, formación académica y servicios especializados en el área de tecnología.

## 🚀 Características

- **Diseño Responsive:** Optimizado para dispositivos móviles, tablets y escritorio.
- **Multilingüe:** Soporte completo para Español e Inglés con persistencia de selección.
- **Estética Premium:** Uso de modo oscuro, tipografía moderna (JetBrains Mono & Plus Jakarta Sans) y micro-animaciones.
- **Optimización de Seguridad:** Implementación de ofuscación Base64 para proteger la dirección de correo electrónico contra bots de spam.
- **Layout Moderno:** Secciones de habilidades y servicios organizadas en tarjetas (cards) con una distribución dinámica.
- **Navegación Fluida:** Barras superior e inferior fijas para un acceso rápido a la información de contacto.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Estilos personalizados, CSS Grid y Flexbox (sin frameworks externos como Tailwind o Bootstrap).
- **JavaScript (Vanilla):** Lógica de traducción, cálculo dinámico de experiencia y efectos de interfaz.
- **FontAwesome:** Iconografía técnica y social.
- **Google Fonts:** Tipografía de alta legibilidad.
